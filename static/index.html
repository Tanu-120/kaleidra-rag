What is Kaleidra?

Kaleidra is a production-style Retrieval-Augmented Generation (RAG) system. Instead of asking an LLM to guess from memory, it finds the right passages from your documents, ranks them carefully, checks for security issues, then answers only from that evidence — and shows you every stage as a “retrieval X-ray.”

01

Ingest & redact

Parse md/html/pdf/docx/csv. Strip PII before anything is embedded so secrets never enter the vector store.

02

Chunk & index

Heading-aware chunks with overlap. Dense vectors (Chroma) + BM25 keyword index + entity co-occurrence graph.

03

Hybrid retrieve

Guards scan the query. HyDE + rewrites broaden recall. BM25 and dense ranks fuse with Reciprocal Rank Fusion.

04

Rerank & answer

Graph hop + cross-encoder + dedupe. Context injection quarantine. Extractive claims with faithfulness scores.

Query path live stages

question → input guard (PII + injection) → query forge (rewrite + HyDE) → BM25 ‖ dense → RRF fusion → graph hop → cross-encoder rerank → dedupe → context guard → generate + faithfulness → output guard

Why each piece exists

HybridKeywords catch exact terms; vectors catch paraphrases. RRF merges ranks without score calibration.
HyDEImagines a fake ideal answer passage, then searches with it — boosts recall on vague questions.
RerankCross-encoder scores query–passage pairs jointly; much sharper than bi-encoder cosine alone.
GraphEntity neighbors surface related chunks the lexical/dense search missed.
GuardsBlock prompt injection, redact PII, quarantine poisoned docs, re-scan the answer.
EvalsSynthetic Q/A + Hit/MRR/nDCG/faithfulness + latency gates pick a production config.
