What Kaleidra does

A production-style Retrieval-Augmented Generation console. Questions are guarded, expanded, retrieved with hybrid search, reranked, checked for poisoned context, then answered as cited claims — not free-form guesses.

01

Ingest & redact

Parse files, strip PII, chunk with headings, build BM25 + vectors + graph.

02

Guard & forge

Block injections, redact query PII, rewrite + HyDE for better recall.

03

Hybrid retrieve

BM25 ‖ dense → RRF → graph hop → cross-encoder → dedupe.

04

Answer safely

Quarantine poisoned chunks, emit grounded claims, scan output.

Stage map

question → input guard (PII + injection) → query forge (rewrite + HyDE) → BM25 ‖ dense → RRF fusion → graph hop → cross-encoder → dedupe → context guard → generate + faithfulness → output guard

Why each piece

Hybrid

Keywords + meaning. RRF merges ranks without score tuning.

HyDE

Search with a hypothetical answer passage for vague questions.

Rerank

Cross-encoder scores query–passage pairs jointly.

Guards

Direct + indirect injection, PII at ingest/query/output.
